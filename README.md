# Evaluating AI Scientists — AAAI-27 Workshop

Static, responsive workshop website prepared for GitHub Pages.

## Publish with GitHub Pages

1. Create a public GitHub repository and copy this entire folder into its root.
2. Push to the `main` branch.
3. In the repository, open **Settings → Pages** and choose **GitHub Actions** as the source.
4. The included workflow will publish the site and automatically set the correct social-preview URL.

The site works as either a project page (for example, `username.github.io/workshop`) or an account/organization page (`username.github.io`).

## Update content
