The AI Scientist Evaluation Challenge

A challenge organized in collaboration with XtalPi, an AI-driven drug discovery company, built on a real-world dataset from molecular property prediction or drug-target interaction.

  1. Home
  2. Challenge

What the challenge asks

Judging finished manuscripts is only part of the problem. The challenge puts both halves of the question in front of the community at once, asking one set of participants to generate science with autonomous systems and another set to build the instruments that assess it. Both halves run on the same real-world data, so the two tracks can be read against each other.

Results are presented at the workshop in a dedicated session with spotlight talks, and the corpus that comes out of the challenge is released publicly.

Two tracks

Track A

Generation

Participants use an AI Scientist system to produce a research report on the provided dataset.

Submissions are judged by automated metrics and expert reviewers.

Track B

Evaluation

Participants build metrics, frameworks, or tools that assess a provided set of AI-generated papers.

Submissions are judged on reliability, scalability, and correlation with expert human judgment.

The dataset

XtalPi provides a real-world dataset drawn from molecular property prediction or drug-target interaction. The exact task and the release date will be announced here.

A lasting community resource

The challenge will yield a publicly released, expert-annotated dataset of AI-generated scientific papers. Work in this area has been held back by the absence of shared, human-labelled material to calibrate against, and this corpus is meant to outlive the workshop itself.
